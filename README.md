
# Bacteria Motion Tracking using Computer Vision

## Overview
This project analyzes bacterial motion using microscopy videos and computer vision techniques.

## Methods
- Image preprocessing (blurring, thresholding)
- Contour detection using OpenCV
- Tracking bacterial movement over time
- Statistical analysis of motion patterns

## Tools
Python, OpenCV, NumPy, SciPy, Pandas

## Results
- Extracted motion trajectories
- Computed velocity and radius changes
- Generated visual plots of bacterial dynamics
